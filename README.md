# Iris Flower Classification

## Project Objective
The objective of this project is to build a Machine Learning model to classify Iris flowers into three species: Setosa, Versicolor, and Virginica based on sepal and petal measurements.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithms
- Logistic Regression
- K-Nearest Neighbors (KNN)

## Project Steps
1. Load the Iris dataset.
2. Perform data cleaning and exploration.
3. Visualize the dataset using graphs.
4. Split the dataset into training and testing sets.
5. Train Machine Learning models.
6. Evaluate model performance using accuracy and confusion matrix.

## Result
The KNN model achieved 100% accuracy and Logistic Regression achieved 96.67% accuracy on the test dataset.
